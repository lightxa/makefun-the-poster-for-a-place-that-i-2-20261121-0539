[The Poster for a Place That Isn't There](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539)

A procedurally drawn travel poster for VELMARA, an invented cliff-top lighthouse town above a lavender sea at dusk, rendered in pure Python stdlib.

## Run it

```sh
python3 main.py
```

This writes the poster to `output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`).
